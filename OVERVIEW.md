Paseo Voice lets you talk continuously with a coordinator about your workspaces. Ask what needs your attention, get an explanation, consult relevant idle workspace agents, or relay routine instructions without repeated confirmation. You can interrupt the coordinator while it speaks.

The sidebar opens a companion browser call page. Desktop calls can use localhost; phone calls use an anonymous Cloudflare tunnel that runs on your laptop. The current tunnel address is discovered automatically. The laptop must stay awake and online. OpenAI handles live audio over WebRTC using a server-side API key; API usage is billed by OpenAI.

Setup requires Node 24+, cloudflared, the local voice service, and Paseo 0.11.2. No Cloudflare account or token is needed. The service reads workspace status and recent conversation excerpts through Paseo's authenticated local SDK. It consults relevant workspaces before relying on general knowledge, treats workspace content as untrusted evidence, and attributes agent reports clearly. Routine messages use delegated judgment without repeated confirmation; consequential or disruptive actions still require specific authorization. It does not automatically approve permissions.

Routine updates can queue while an agent is busy and deliver when idle. Prompt updates can apply between turns; refresh/reconnect retains bounded text context and queued job references. The SDK lacks atomic idle-only delivery, so another client can race with the last idle check. A full tunnel restart still changes the anonymous hostname. This is a prototype with on-demand context and bounded local handoff, not complete cross-device memory. iPhone screen-lock behavior and car audio routing require device testing. The plugin does not replace Paseo's built-in voice controls.

Workspace overviews expose attached PR mappings, names, paths, branches and worktree names with cache qualifiers. The owner can enable voice display-title renames in laptop settings; the server requires a recent user turn and revalidates the workspace before writing. Otherwise renames remain proposals. Creation tools prepare proposals only; completion stays in Paseo. A shared voice link does not establish owner identity.
